# 📰 THE NEWSPAPER ROOM

> a tiny editorial studio for curious creators ♡

**The Newspaper Room** is a browser-based newspaper and editorial publishing tool where you can create, edit, design, and export your own digital newspaper pages.

Designed to feel like a little independent publishing desk, the project combines **editorial typography, newspaper layouts, creative controls, and interactive page editing** into one playful frontend experience.

---

## ୨୧ ABOUT

The Newspaper Room is a frontend publishing playground inspired by newspapers, magazines, independent publications, and digital editorial design.

Instead of using a traditional form-based editor, the interface is designed like an **editorial workstation** where you can build your own tiny publication.
