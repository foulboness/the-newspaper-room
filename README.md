# 📰 THE NEWSPAPER ROOM

> a tiny editorial studio for curious creators ♡

**The Newspaper Room** is a browser-based newspaper and editorial publishing tool where you can create, edit, design, and export your own digital newspaper pages.

Designed to feel like a little independent publishing desk, the project combines **editorial typography, newspaper layouts, creative controls, and interactive page editing** into one playful frontend experience.

---

## ✦ FEATURES

### 🗞️ Multi-page newspaper editor

Create different sections of your publication:

* **01 — Front Page**
* **02 — Tech & Culture**
* **03 — Features**

Each page has its own editorial layout and content.

### ✎ Live editing

Edit your newspaper directly from the editor panel.

You can change:

* Masthead
* Date
* Headlines
* Subheadlines
* Articles
* Sidebar stories
* Quotes
* Feature content
* Interviews

Changes appear directly in the newspaper preview.

### ◌ Newspaper templates

Choose from different editorial starting points:

* The Daily Byte
* Midnight Herald
* The Archive
* Culture Paper
* The Weekly
* Deadline

### Aa Typography controls

Experiment with different visual styles:

* Classic
* Modern
* Editorial
* Mono

### ▧ Paper themes

Change the appearance of your newspaper:

* White
* Warm
* Grey
* Black

### 💾 Local saving

Your current edition can be saved using the browser's `localStorage`, allowing you to return to your work without needing a backend.

### ↓ PNG Export

Export the current newspaper page as a high-resolution **PNG image**.

Perfect for:

* Portfolio pieces
* Social media graphics
* Editorial mockups
* Design experiments
* Digital zines
* Creative projects

## ✦ DESIGN DIRECTION

The interface takes inspiration from:

```text
EDITORIAL DESIGN
       +
NEWSPAPER LAYOUTS
       +
DIGITAL PUBLISHING
       +
MODERN UI DESIGN
```

The visual language uses:

* Strong typography
* Structured grids
* Thin editorial borders
* Oversized headlines
* Restrained colour
* Paper-like surfaces
* Newspaper-inspired hierarchy

The goal was to make the interface feel more like an **actual publishing desk** than a traditional web form.

## ✦ PAGE SYSTEM

The newspaper is split into three editorial sections.

### 01 / FRONT PAGE

The main entrance to the publication.

Includes:

* Lead story
* Breaking news

* Sidebar
* Pull quote

### 02 / TECH & CULTURE

A magazine-style page focused on technology and culture.

Includes:

* Main technology story
* Culture article
* Trend report
* Quick reads
* Editorial quote

A long-form editorial layout.

Includes:

* Long-read content
